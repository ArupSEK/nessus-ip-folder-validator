# Assumptions

## 2026-07-30

1. The current Streamlit starter is not the final architecture and will be superseded by the FastAPI/React stack.
2. Phase 1 may introduce new backend/frontend directories without deleting the current starter immediately.
3. Live Nessus credentials are not available for development, so Nessus integration will be tested with mocks first.
4. PostgreSQL and Redis service definitions can be added before live runtime validation in this environment.
5. The safer requirement is to preserve the existing starter while the new architecture is introduced incrementally.
